# REAL | AI · 中国短剧同故事配对

现有 5 组配对、18 对 clips；最新新增《江先生，别太野》4 对。
1. 《江先生，别太野》· 花店与闺蜜来电：4 对。
2. 《富二代》· 同故事的真人 / AI 首集：4 对。
3. 《老太跑龙套》· 古代人物来到现代街景：4 对。
4. 《他深情侵入》 /《深情侵入，予你余生》：3 对。
5. 《那年冬至》· 真人 / 同名 AI 创作版：3 对。

页面左 REAL、右 AI，可切换匹配片段、裁剪连续场景、完整公开首集。
默认关闭外挂字幕；裁剪版代表帧检查未见硬字幕，不保证所有帧绝无文字。
字幕为本地 ASR，可能有错字和时间漂移；源字幕与 AI 标签保存在原片中。
两侧独立原速播放，不变速拟合。时间以本地原始下载文件为准。

metadata/dataset.json：来源、对应关系、匹配程度、证据等级和裁剪参数。
metadata/pairs.csv：18 对片段索引；source_manifest.json：10 个原文件来源与 SHA256。
metadata/expansion-audit.json：本轮 14 个 AI 版本的实际画面筛选记录。
metadata/checksums.sha256：发布文件校验表；validation.json：解码及复制校验。

10 个完整公开首集 + 46 个裁剪场景/片段 = 56 个 MP4。
公开首集不等于全剧。原文件保持下载字节，派生视频为 H.264 CRF18；
发布时逐字节复制，不额外压缩，不去字补绘、不插帧、不超分。

《深情侵入，予你余生》特定版本缺制作方声明，保留 B 级证据；
《那年冬至》美化感较强，作为补充。此次新增江先生有明确 AI 版命名与真人演员表，模型未知。
同名《莞城往事》人物与故事不同，未当成同 IP；动画感明显候选未发布媒体。
本数据集不是逐帧对齐真值；共享故事/素材应放在同一评估划分。

GitHub Pages 托管，无遥测、第三方脚本或网络字体。
完整下载后可双击 index.html 离线使用，无需运行服务器。
素材版权属于原权利人；未核验公开再分发许可，本仓库不新增素材授权。
