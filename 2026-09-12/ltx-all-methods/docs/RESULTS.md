# 已完成的速度与相似度参考

以下是固定 LTX 2B 0.9.6、A800 80GB、1216×704、121 帧、50 步、dynamic flow 0.1 下的实测，供迁移后检查数量级。SSIM / LPIPS 与同种子原版比较，不是官方 VBench 总分，也不是同质量配平后的排名。

发布检查发现同一生成进程内，x264 会将相同的原始 RGB 编码为不同 MP4，仅固定线程也不足以消除差异。噪声、VAE 浮点输出、量化 RGB 和显式转换 YUV 的哈希在控制实验中均一致，不一致发生于编码。发布包统一使用独立 CPU 编码进程、固定单线程、明确的帧时间戳和 BT.601 颜色转换，保留 fast preset、CRF18；完整真实视频连续五次重复编码已验证。下面原有/新增四案例表保留历史自动编码的真实结果，不能与新版固定编码的单案例结果混成一组；新服务器的完整 VBench 应全部使用同一新版本重新生成。

新 ProfilingDiT 用 946 条短序列和 32 条长序列做离线统计，再用独立 8 条验证选择档位；12 候选共 96 次验证完成后固定配置，下面测试集未参与选档。慢档缓存层 [15,16]，快档 [15,16,17,19]，刷新间隔均 2→1。达到验证平均质量门槛后，两档在独立样本上仅有约 1%–3% 加速。

完整精度的汇总、逐样本指标与视频哈希见 [reference_results.json](../data/reference_results.json)。在线时间包含文本编码、采样、缓存/恢复、解码和视频编码；模型装载、离线统计及评分除外。完整官方 VBench 的 87,080 个视频尚未在这里运行，运行方式见 [BENCHMARK.md](BENCHMARK.md)。

我们的恢复器训练使用过全部 VBench 短提示词，ProfilingDiT v2 也使用 VBench 作离线校准。必须披露这项重合，不能把完整 VBench 当作恢复器的未见提示词测试。NaviCache 为跨模型移植，SenCache 的官方灵敏度来自 LTX 0.9.1，ProfilingDiT 的 RGB 前景分割与论文 PCA 流程不同。
