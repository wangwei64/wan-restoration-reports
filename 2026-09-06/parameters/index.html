03 / 结构保持一致

只调节“什么时候再修一次”

先恢复，再检查剩余修正

原生前十步得到 latent，既有特征学生与恢复网络给出恢复终点和误差先验。主体与恢复风险决定互斥三区；可靠 token 可以直接采用恢复结果。

第11～49步，每一步做轻量判断：恢复是否可靠、区域是否重要、最近真实修正是否稳定、已经跳过多久。分数达到 β 才执行该 token 的 Wan 更新。

门槛改变，流程保持

β 从0.75提高到2.0，只改变触发灵敏度。主体也能跳过；直接恢复区始终0次更新；第50步统一刷新所有参与细化的 token，按原三区权重融合。

跳过 Wan 的 token 仍用真实历史推进 latent 并提供上下文。不读取 GT、不在线解码 RGB、不新增网络或训练。该评分是经验代理量，β 不代表置信度百分比或视觉误差上限。

精确判据与可复现设置

S = I × h² × [ρ / (1 + E) + (K + N) / A]；S ≥ β 时更新。I = 1 + 3×主体概率 + 0.5×细节热图；ρ 为校准恢复风险相对局部容差的比值；E 为真实稳定证据；K 与 N 为自身和邻域观察到的新修正偏差；A 为修正幅度与误差先验的归一化尺度。h 按实际噪声进程累计。仅 β 在五组中不同。
